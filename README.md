# Infinity AI — Identidade visual

Site one-page responsivo da identidade visual Infinity AI.

## Estrutura
- `index.html`: página principal, estilos e interações.
- `assets/images/`: imagens WebP e logo SVG.

## Tipografia
- **Inter**: família principal para textos, interface e navegação.
- **Manrope**: família secundária para títulos e chamadas.

As fontes são carregadas pelo Google Fonts; é necessária conexão com a internet para obter os arquivos tipográficos.

## Executar localmente
Abra `index.html` no navegador ou execute `python -m http.server 8000` nesta pasta e acesse `http://localhost:8000`.

## Publicar no GitHub Pages
Envie `index.html`, `README.md` e a pasta `assets/` para a raiz da branch `main`; em Settings → Pages, selecione `main` e `/(root)`.
